# Parcial de Programación — Gestor de Turnos

Proyecto Java Swing organizado por paquetes:
- `modelo`: Cliente y Turno
- `gestion`: GestorTurnos
- `interfaz`: VentanaPrincipal

El punto de entrada está en `interfaz.VentanaPrincipal`. Requiere un JDK para compilar y ejecutar. Código copiado desde la carpeta original del parcial; no incluye materiales de Redes.

# Inicio Nakano

Proyecto personal formado por una página de nueva pestaña y una extensión de Chrome que permite usarla como página de inicio del navegador.

## Contenido

- `web/`: página web con galería de fondos, accesos rápidos y controles de presentación.
- `extension/`: extensión Manifest V3 para cargar la experiencia al abrir una pestaña nueva.

## Probar la página web

Abre `web/inicio.html` en un navegador moderno. Algunas funciones del navegador pueden requerir ejecutarla desde un servidor local.

## Instalar la extensión en Chrome

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador**.
3. Selecciona **Cargar descomprimida**.
4. Elige la carpeta `extension/`.

La extensión reemplaza la página de nueva pestaña. Para actualizarla después de editar los archivos, pulsa el botón de recarga en `chrome://extensions`.
